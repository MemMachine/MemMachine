# Issues

The issue templates set each issue's type: `Bug`, `Feature`, `Documentation`,
or `Question`. Correct the type when an issue was filed under the wrong one.

Labels used in triage:

- `documentation`
- `good first issue`
- `priority: high`, `priority: medium`, and `priority: low`
- `keep-open`: exempts an issue from the stale workflow
  (`.github/workflows/stale.yml`), which labels idle issues `Stale` and later
  closes them.
